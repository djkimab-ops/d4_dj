# data/ — 원본 데이터(읽기만)

(가상) 한빛정밀(주)의 **합성 데이터**입니다. 실제 회사 · 사람 · 거래가 아닙니다.
이 폴더의 파일은 고치지 않습니다 — 화면 · 계산 코드는 `app/` · `lib/`에 씁니다. 데이터 파일은 서버 코드에서 `import`로 읽습니다.

| 파일 | 내용 | 쓰는 곳 |
|---|---|---|
| `buyers.json` | 바이어 150곳 — 2026-09-30 현황(3일차 실습 D의 바이어 보드와 같은 숫자) | 첫 화면 · 4일차 실습 D · 5일차(DB에 넣는 처음 데이터) |
| `buyers.csv` | `buyers.json`과 같은 내용(엑셀용, UTF-8). `signals`는 ` \| `로 이어 붙임 | 눈으로 볼 때 |
| `fx_fallback.json` | 환율 저장본 — 환율 API가 안 될 때 쓰는 값 | 5일차 실습 D |
| `tone_matrix.csv` | 독촉 단계 × 등급 → 말투(T1 · T2 · T3) | 5일차 실습 D |
| `dunning_templates.md` | 독촉 메일 틀 T1–T3 · 꼭 넣을 것 · 넣지 않을 것 | 5일차 실습 D |

## buyers.json — 키 16개
| 키 | 뜻 | 형식 · 값 |
|---|---|---|
| `id` | 바이어 번호 | `B001`–`B150` |
| `name` | 바이어 이름(가상 회사) | 영문 |
| `countryCode` | 나라 코드(영문 3글자) | `USA` · `CHN` · `DEU` … 20개 |
| `countryKo` | 나라 이름(한국어) | `미국` · `중국` · `독일` … |
| `region` | 지역 6개 | `동남아·남아` · `동아시아` · `북미·중남미` · `서유럽` · `중동·아프리카` · `중동부유럽` |
| `industry` | 업종 6개 | `완성품 제조(OEM)` · `유통` · `플랜트 시공(EPC)` … |
| `paymentMethod` | 결제방식 7개 | `외상(O/A)` · `인수인도(D/A)` · `사전 송금` · `일람불 신용장` … |
| `termsDays` | 결제기간 — 선적 뒤 며칠 안에 내기로 했나(일) | 정수 0 · 30 · 60 · 90 |
| `openArUsd` | 받을 돈(채권) — 아직 받지 못한 금액(달러) | 정수 · 0인 곳도 있음 |
| `overdueUsd` | 그중 결제기일이 지난 금액(연체, 달러) | 정수 |
| `pctAr31p` | 받을 돈 중 기일을 31일 넘긴 몫 | 0–1 소수(0.36 = 36%) · 받을 돈이 0이면 `null` |
| `oldestOpenDays` | 가장 오래 밀린 인보이스가 기일을 넘긴 날 수 | 정수 · 0 = 밀린 것 없음 |
| `avgDaysLate12m` | 최근 1년, 늦게 낸 건들이 평균 며칠 늦었나 | 소수 · 최근 1년 외상 거래가 없으면 `null` |
| `pd30d` | 위험 점수 — 앞으로 30일 안에 결제가 크게 늦어질 가능성 | 0–1 소수(0.17 = 17%) |
| `grade` | 신호등 등급 S · A · B · C(S 안전 → C 위험) | 이 값을 그대로 쓴다 — 다시 계산하지 않는다 |
| `signals` | 쉬운 말 위험 신호(최대 3개, 빈 칸은 뺌) | 글자 목록 · '눈에 띄는 위험 신호 없음'이라는 문장일 수도 있음 |

- 화면에서 `null`은 `—`로 보입니다(`lib/format.ts`).
- 금액은 `usd()`, 비율은 `pct()`, 정수는 `int()`로 형식을 맞춥니다.

## fx_fallback.json — 환율 저장본
| 키 | 뜻 |
|---|---|
| `provider` · `endpoint` | 환율 제공처(Frankfurter, 키 없음)와 부른 주소 |
| `savedAt` | 저장한 시각(한국 시각, ISO 8601) — 화면에 '대체 값 · 저장 시각 …'으로 보여 준다 |
| `latest` | 저장할 때의 최신 환율 — API 응답 원문 그대로: `[{"date","base","quote","rate"}, …]` |
| `2026-09-30` | 기준일 환율 — 같은 모양 |

- 통화는 `base` = USD, `quote` = KRW · EUR · JPY · CNY. `rate` = 1달러에 그 통화 얼마.
- 환율은 참고값입니다. 저장본은 오래될 수 있으니 '대체 값'이라고 꼭 표시합니다.

## tone_matrix.csv
- 줄 = 독촉 단계(`D+7` · `D+15` · `D+30`), 칸 = 등급(S · A · B · C), 값 = 말투 `T1`(상냥) · `T2`(단호) · `T3`(마지막 안내).
