# CLAUDE.md에 더할 절의 틀 — 내 해커톤 프로젝트

> H2에서 AI가 아래 틀을 채워 `CLAUDE.md` **맨 끝에** 절 하나로 더합니다. 위쪽의 원래 규칙은 한 줄도 고치지 않습니다. 10–15줄.
> 이 파일은 틀이라 고치지 않습니다. 값은 `SPEC.md`에서 옮겨 적고, `SPEC.md`에 없는 것은 `(확인 필요)`로 둡니다.

````markdown
## 내 해커톤 프로젝트 — {앱 이름}
- 한 줄: {누가} · {언제} · {무엇을}
- 사용자: {직무 하나}
- 화면(3개 이하): `/` {첫 화면} · `/{주소}` {화면 이름}
- 데이터: {파일 · 줄 수} — 모두 가상(이름 옆 (가상) · 김○○ · @….example)
- 저장: {없음 | 브라우저(localStorage) | DB(이 프로젝트의 새 Supabase)}
- 앱 안 AI: {없음 | AI가 미리 만든 결과 data/ai_….json — 앱에는 키 없음}
- 하지 않는 것: {로그인 · 실제 발송 · 실데이터 · …}
- 발표 장면: SPEC.md의 시나리오 1 — 이것이 운영 주소에서 끝까지 되기 전에는 다른 기능을 시작하지 않는다
- 범위를 넘는 요청은 만들기 전에 guide/day6_hackathon.md 「1」의 '자르는 법'으로 줄인 안부터 보여 준다
- 끝날 때마다 `npm run build` 통과 + SPEC의 확인 기준 3줄
````
