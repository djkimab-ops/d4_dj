# guide/ — 실습 작업 안내서

AI(Claude Code)가 읽고 따르는 안내서입니다. 프롬프트는 '목적 한 줄 + 안내서의 절'만 짧게 쓰고, 긴 규칙은 여기에 있습니다.
사람이 읽어도 됩니다 — 고치지는 않습니다. 고친 판은 `npm run guide:update`로 받습니다.

| 파일 | 언제 | 무엇 |
|---|---|---|
| `design_rules.md` | 언제나 | 화면 규칙 — 색 · 글자 · 숫자 · 390px · 부품 쓰는 법 |
| `day4_lab_d.md` | 4일차 실습 D | 첫 웹앱 + 배포 — 바이어 목록 · 상세 쪽 |
| `day5_lab_c.md` | 5일차 실습 C | 확인 기록 — DB 붙이기 |
| `day5_lab_d.md` | 5일차 실습 D | 환율 타일 + AI 독촉 초안 승인 대기열 |
| `day6_hackathon.md` | 6일차 | 내 아이디어 해커톤 — 크기 · 데이터 · 비밀 · 빌드의 선과 일하는 순서 |

모든 안내서에 함께 적용되는 저장소 규칙은 `CLAUDE.md`(맨 위 폴더)에 있습니다.
