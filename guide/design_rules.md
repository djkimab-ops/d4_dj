## 1. 색 · 글자 · 간격 — 토큰만

색은 `app/globals.css`의 `@theme` 토큰으로 만든 Tailwind 클래스만 쓴다.

| 토큰 | 값 | 클래스 예 | 쓰는 곳 |
|---|---|---|---|
| `bg` | #ffffff | `bg-bg` | 바탕 |
| `surface` | #f6f7f9 | `bg-surface` | 카드 · 표 머리 · 상자 면 |
| `line` | #e3e6ea | `border-line` | 1px 테두리 · 구분선 |
| `ink` | #1b1f24 | `text-ink` | 본문 · 숫자 |
| `muted` | #5b6470 | `text-muted` | 설명 · 기준일 · 표 머리 |
| `accent` | #1f5fbf | `text-accent` · `bg-accent` · `border-accent` | 링크 · 고른 칩 · 주된 단추 하나 |
| `warn` | #b42318 | `text-warn` · `border-warn` | 경고 글 |
| `grade-s` · `grade-a` · `grade-b` · `grade-c` | #1e7f4f · #4d7c0f · #a15c00 · #b42318 | `text-grade-c` · `bg-grade-c` · `border-grade-c` | 등급 표시 — 언제나 글자(S · A · B · C)와 함께 |

- Tailwind 기본 색(`bg-blue-500` · `text-gray-600` · `from-purple-500` …)과 임의 값(`text-[#123456]` · `p-[13px]`)은 쓰지 않는다. 새 색이 꼭 필요하면 `@theme`에 토큰을 하나 더하고, 더했다고 알린다.
- 대비: 위 토큰은 `bg` · `surface` 바탕에서 모두 4.5 : 1 이상이고, 흰 글자를 `accent` · 등급 색 위에 얹어도 4.5 : 1 이상이다. 토큰을 바꾸거나 더하면 대비를 **코드로 계산**해 4.5 이상인지 보여 준다.
- 간격은 Tailwind 기본 단계(`p-2` · `p-4` · `gap-3` …, 4px 배수)만. 모서리는 `rounded`–`rounded-lg`(4–8px). 그림자는 없음 또는 `shadow-sm` 하나.
- 글꼴은 `globals.css`의 `font-sans`(시스템 글꼴) 그대로. 웹 글꼴 · Google Fonts는 더하지 않는다.
- 같은 모양이 두 번 나오면 `components/`의 부품을 먼저 쓴다. 새 부품은 `components/`에 한 파일로.

## 2. 'AI 티' 금지 10가지

AI가 '예쁘게'를 들으면 먼저 꺼내는 것들이다. 어느 화면에서나 피한다.

| 금지 | 대신 |
|---|---|
| 보라 · 파랑 그라데이션 | 흰색 · 연회색 바탕 + 강조 1색 |
| 이모지 아이콘 | 글자 라벨, 꼭 필요하면 선 아이콘(SVG) |
| 모든 카드에 그림자 | 1px 테두리나 바탕색 차이 |
| 유리(blur) 효과 남발 | 불투명한 면 |
| 가운데 정렬 일색 | 글은 왼쪽, 숫자는 오른쪽 정렬 |
| 'Welcome back!' 같은 빈말 | 기준일 · 데이터 범위처럼 쓸모 있는 한 줄 |
| 무지개색 차트 | 회색 + 뜻이 있는 1–2색(등급 색) |
| 지나치게 둥근 모서리 | 4–8px |
| 의미 없는 장식 그림 | 빈칸(여백) |
| 영어 더미 글 | 우리말 진짜 문장 |

## 3. 데이터 화면 기본기

- **숫자**는 오른쪽 정렬 · 천 단위 쉼표 · 단위($ · 곳 · % · 일), 그리고 `className="num"`(자리 맞춤 + 한 줄). 금액 · %는 숫자 가운데서 줄을 바꾸지 않는다 — 칸보다 길면 그 숫자의 글자를 한 단계 줄인다.
- **형식**은 `lib/format.ts`만 쓴다 — 금액 `usd()` · 원화 `krw()` · 비율 `pct()`(0–1 값 → `77.0%`) · 개수 `int()` · 시각 `kst()`(서버에서). 값이 없으면 이 함수들이 `—`를 돌려준다. 소수 한 자리 일수(예: `30.8일`)만 `toFixed(1)`을 쓴다.
- **등급**은 데이터의 `grade` 칸 그대로 쓰고 다시 계산하지 않는다. 화면에는 `GradeBadge`(색 + 글자) — 색만으로 말하지 않는다.
- KPI는 4개 이하, '상위 N'은 10. 나머지는 상세 쪽이나 '전체 목록'으로.
- 모르는 값은 지어내지 않고 '확인 필요'. 숫자는 코드로 계산한 값만 화면에 둔다.
- 쪽 머리에 기준 한 줄(`PageHeader`의 `asof` — 예: '2026-09-30 · (가상) 합성 데이터').

## 4. 한국어 · 가상 데이터

- 화면 글은 한국어. 바이어 이름 · 나라 코드 같은 고유 이름만 원문 그대로. 영어 더미 글(Lorem ipsum · Dashboard · Welcome)은 쓰지 않는다.
- `word-break: keep-all`(이미 `body`에 있다) · 이모지 없음.
- 회사는 '(가상) 한빛정밀(주)', 데이터는 합성. 실명 · 실제 회사 · 실제 이메일(쓰려면 `@….example`만) · 계좌 · 전화번호는 넣지 않는다.
- 레이아웃의 바닥글 '(가상) 한빛정밀(주) · 합성 데이터 · 결정은 사람이 합니다'는 지우거나 줄이지 않는다(6일차 해커톤은 `guide/day6_hackathon.md` 「3」의 바닥글로 한 번 바꾸고, 그 뒤로는 그대로).
- 위험 신호는 '이유'로만 쓴다 — '때문에 망한다'처럼 원인을 단정하지 않는다.

## 5. 휴대폰 먼저(390px)

- **390px 폭에서 가로 스크롤 없음.** 넓은 표는 `DataTable`을 쓴다(md 아래에서 저절로 카드). 긴 이름은 줄을 바꿔도 되지만 숫자는 한 줄.
- 누르는 것(링크 · 칩 · 단추)은 높이 44px 이상(`min-h-11`), 서로 8px 이상 떨어지게.
- 휴대폰에서는 위에서 아래로 한 줄 흐름 — 옆으로 나란히는 2개까지.
- 사람이 확인하는 법: 브라우저 F12 → 기기 툴바(Ctrl+Shift+M) → 너비 390.

## 6. 그림 · 바깥 요청 · 브라우저 기능

- 그림 파일 · 외부 이미지 · CDN 스크립트 · 외부 글꼴은 넣지 않는다. 아이콘이 필요하면 짧은 SVG 코드(선 아이콘)를 부품 안에, 앱 아이콘이 필요하면 코드로 만든다(예: Next.js 규칙 파일 `app/icon.tsx`).
- 차트 라이브러리 없이 — 막대는 `BarRow`나 div 너비로, 선 · 원은 손으로 쓴 SVG로.
- **바깥 서비스**(키가 필요한 API · 바깥 데이터)는 서버에서만 부른다(route handler · 서버 컴포넌트). 키는 `.env`에만 두고 브라우저로 보내지 않는다(`NEXT_PUBLIC_`에 비밀 금지).
- **브라우저 내장 기능**은 키 없이 `'use client'` 부품에서 쓸 수 있다 — 음성 인식(SpeechRecognition) · 읽어 주기(speechSynthesis) · 알림(Notification) · 진동 · 클립보드 · 홈 화면 설치(웹 앱 매니페스트).
  - 마이크 · 알림처럼 권한을 묻는 기능은 **사람이 단추를 눌렀을 때만** 시작한다(쪽을 열자마자 묻지 않는다).
  - 안 되는 브라우저에서는 한 줄 안내를 보여 주고 나머지 화면은 그대로 동작하게(예: '이 브라우저는 음성 인식을 지원하지 않습니다 — Chrome · Edge에서 열어 주세요').
  - **알림은 PC 브라우저(Chrome · Edge 등) 기준이다.** 휴대폰은 Android가 서비스 워커(`showNotification`), iPhone이 홈 화면에 추가한 웹앱(iOS 16.4+)에서만 알림을 띄우므로, 알림을 제안할 때는 'PC 전용'이라고 적는다. `new Notification(…)`은 `try/catch`로 감싸고, 실패하면 같은 내용을 화면 안 `Notice`로 보인다 — Android Chrome은 `'Notification' in window`가 참인데도 여기서 오류가 난다.
  - 진동(`navigator.vibrate`)은 iPhone에서 되지 않는다 — 있을 때만 부르고, 없어도 기능은 그대로 돌게.
  - 들은 말 · 읽은 글은 어디에도 저장하거나 보내지 않는다.

## 7. 서버와 브라우저 나누기

- 쪽(`page.tsx`)은 서버 컴포넌트가 기본이다 — 데이터를 읽고(`lib/buyers.ts`) 계산한 뒤(`lib/metrics.ts`) 부품에 props로 준다.
- `'use client'`는 누르기 · 입력 · 브라우저 기능이 필요한 **작은 부품에만**. 그 파일은 `data/` · `lib/db.ts` · `process.env`를 import하지 않는다 — 화면에 쓸 값만 props로 받는다(150곳 전부가 아니라 필요한 만큼).
- 거르기 · 정렬처럼 주소로 나타낼 수 있는 것은 주소(`?grade=C`)와 링크로 한다 — 그래야 주소를 보내면 받은 사람도 같은 화면을 본다.
- 안쪽 링크는 `next/link`의 `Link`. 시각 · 날짜는 서버에서 형식을 맞춘다(브라우저마다 달라 화면이 깜빡이지 않게).
